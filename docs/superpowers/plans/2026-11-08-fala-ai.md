# Fala Aí — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serviço que transforma as Newsletters pendentes do Gmail em um Episódio diário de podcast em pt-BR, conversado por Dora e Alex, publicado num feed RSS privado na tailnet.

**Architecture:** Um app Python (Starlette) no servidor é dono de todo o estado (SQLite + volume de arquivos), orquestra o Job em estágios com checkpoint e serve feed, mp3 e métricas. O laptop só fornece modelos por HTTP pela Tailscale: Ollama (LLM) e um serviço Kokoro (TTS) do mesmo repo. O pipeline é síncrono e roda numa thread disparada por `POST /jobs`.

**Tech Stack:** Python 3.12, `uv`, Starlette + uvicorn, httpx, google-api-python-client + google-auth-oauthlib, markdownify, feedgen, prometheus-client, ffmpeg, Kokoro (extra `tts`, só no laptop), pytest + respx, Docker Compose com sidecar Tailscale.

**Spec:** `CONTEXT.md` (glossário), `docs/adr/0001-servidor-orquestra-laptop-fornece-modelos.md`, `docs/adr/0002-roteiro-em-estagios-com-checkpoint.md`, `docs/adr/0003-podcast-privado-na-tailnet.md`. Executores leem os quatro antes de começar.

## Global Constraints

- Python `3.12` (fixado em `.python-version`); dependências gerenciadas só por `uv`; nenhuma task além da Task 1 edita `pyproject.toml` ou `uv.lock`.
- Identificadores de código usam os termos do glossário sem acento: `Newsletter`, `Item`, `Topico`, `Pauta`, `Fala`, `Apresentador`, `Roteiro`, `Episodio`, `Shownotes`, `Job`.
- Apresentadores: `"dora"` (voz Kokoro `pf_dora`, conduz a pauta) e `"alex"` (voz `pm_alex`, comenta e contextualiza). Tom descontraído e informativo, pt-BR.
- LLM padrão: `qwen3:30b-a3b-instruct-2507-q4_K_M` via Ollama em `http://100.74.37.102:11434`; `keep_alive` `"5m"` entre chamadas; descarregar com `keep_alive: 0` antes do TTS.
- Teto do Episódio: `15` minutos a `150` palavras/minuto = `2250` palavras. Tópicos excedentes vão só para as Shownotes.
- Áudio: mp3 mono, `64k`, pausa de `300` ms entre Falas, sem vinheta; Episódios nunca são apagados.
- Gmail: label `newsletter`, pendente = `label:newsletter in:inbox`; escopo `https://www.googleapis.com/auth/gmail.modify`; arquivar (remover `INBOX`) só depois do Episódio publicado.
- Texto de Newsletter enviado ao LLM limitado a `30000` caracteres.
- Feed e mp3 servidos só pela tailnet, pelo próprio app; nada público.
- Testes nunca chamam Gmail, Ollama ou Kokoro reais; usam os dublês de `tests/fakes.py`.

## Review Focus

1. Laptop desliga/dorme no meio do Job (httpx `ConnectError`) → Job termina em `erro`; o próximo `POST /jobs` retoma sem refazer extração, pauta nem blocos já salvos. Teste na Task 7.
2. Uma Newsletter cuja extração falha (JSON inválido, timeout) → o Job segue sem ela, e ela não é arquivada (continua pendente). Teste na Task 7.
3. Newsletter que chega durante o Job → não entra no Episódio e não é arquivada. Teste na Task 7.
4. LLM devolve índices de Item inexistentes, apresentador desconhecido ou Fala vazia → descartados sem quebrar. Testes na Task 4.
5. Dois `POST /jobs` seguidos → o segundo recebe `409`; `GET /episodes/../falaai.db` → `404`. Testes na Task 8.

## Paralelização

O trabalho roda em **ondas**. Dentro de uma onda, as tasks não compartilham arquivos e dependem só de interfaces já fixadas pela Task 1, então rodam ao mesmo tempo, cada agente escritor em `isolation: "worktree"`. O thread principal faz merge dos branches ao fim de cada onda e roda a suíte completa antes de abrir a próxima.

| Onda | Tasks | Quem | Modelo |
|---|---|---|---|
| 0 | Task 1 — Fundação (contratos, deps, dublês) | thread principal | opus |
| 1 | Tasks 2, 3, 4, 5, 6 em paralelo (5 agentes) | subagentes em worktree | sonnet |
| 2 | Task 7 — Orquestração do Job | thread principal | opus |
| 2 | Tasks 8 e 9 em paralelo com a 7 | subagentes em worktree | sonnet |

Arquivos-gargalo (`pyproject.toml`, `uv.lock`, `src/falaai/domain.py`, `src/falaai/ports.py`, `src/falaai/config.py`, `src/falaai/cli.py`, `tests/fakes.py`) pertencem à Task 1. Se uma task da onda 1 ou 2 precisar mudar um deles, ela para e reporta ao thread principal em vez de editar.

```python
from dataclasses import dataclass, field
from datetime import date, datetime
from enum import StrEnum
from typing import Literal

Apresentador = Literal["dora", "alex"]

@dataclass(frozen=True)
class Newsletter:
    gmail_id: str
    remetente: str
    assunto: str
    recebida_em: datetime
    texto: str  # markdown, já truncado em Config.texto_max_chars

@dataclass(frozen=True)
class Item:
    titulo: str
    descricao: str
    link: str | None
    fonte: str
    newsletter_id: str

@dataclass(frozen=True)
class Topico:
    titulo: str
    itens: tuple[Item, ...]
    palavras_alvo: int

@dataclass(frozen=True)
class Pauta:
    topicos: tuple[Topico, ...]
    fora_do_audio: tuple[Item, ...]

@dataclass(frozen=True)
class Fala:
    apresentador: Apresentador
    texto: str

@dataclass(frozen=True)
class Roteiro:
    abertura: tuple[Fala, ...]
    blocos: tuple[tuple[Fala, ...], ...]  # um por Topico, mesma ordem da Pauta
    fechamento: tuple[Fala, ...]

    def falas(self) -> list[Fala]: ...      # abertura + blocos achatados + fechamento
    def palavras(self) -> int: ...          # soma de len(texto.split())

@dataclass(frozen=True)
class Episodio:
    job_id: int
    titulo: str
    data: date
    arquivo: str            # nome do arquivo, sem diretório
    duracao_s: float
    tamanho_bytes: int
    shownotes: tuple[Item, ...]
    publicado_em: datetime
    id: int | None = None

class JobStatus(StrEnum):
    RODANDO = "rodando"
    SUCESSO = "sucesso"
    ERRO = "erro"
    SEM_EPISODIO = "sem_episodio"

class Estagio(StrEnum):
    COLETA = "coleta"
    EXTRACAO = "extracao"
    PAUTA = "pauta"
    DIALOGO = "dialogo"
    AUDIO = "audio"
    PUBLICACAO = "publicacao"
    ARQUIVAMENTO = "arquivamento"

@dataclass
class Job:
    id: int
    status: JobStatus
    estagio: Estagio
    iniciado_em: datetime
    modelo: str
    terminado_em: datetime | None = None
    erro: str | None = None
```

### Task 4: Geração do Roteiro — cliente Ollama e estágios de LLM (onda 1)

**Files:**
- Create: `src/falaai/llm.py`, `src/falaai/roteiro/extracao.py`, `src/falaai/roteiro/pauta.py`, `src/falaai/roteiro/dialogo.py`, `src/falaai/roteiro/prompts.py`
- Test: `tests/test_llm.py`, `tests/test_extracao.py`, `tests/test_pauta.py`, `tests/test_dialogo.py`

**Interfaces:**
- Consumes: `Llm`, `Newsletter`, `Item`, `Topico`, `Pauta`, `Fala`, `Roteiro`, `FakeLlm` (Task 1).
- Produces:
  - `class OllamaLlm(url: str, modelo: str, num_ctx: int = 16384, timeout_s: float = 1800)` implementa `Llm`:
    - `json()` faz `POST {url}/api/chat` com `{"model", "messages": [system, user], "format": schema, "stream": false, "keep_alive": "5m", "options": {"num_ctx": num_ctx, "temperature": 0.7}}` e devolve `json.loads(message.content)`. Erros de rede ou JSON inválido propagam.
    - `descarregar()` faz `POST {url}/api/generate` com `{"model", "keep_alive": 0}`.
  - `extrair_itens(llm: Llm, newsletter: Newsletter) -> list[Item]`: o schema pede `{"itens": [{"titulo", "descricao", "link"|null}]}`; `fonte` = `newsletter.remetente`; Itens com título vazio são descartados.
  - `montar_pauta(llm: Llm, itens: Sequence[Item], palavras_max: int) -> Pauta`:
    - O LLM recebe os Itens numerados e devolve `{"topicos": [{"titulo", "indices": [int], "palavras_alvo": int}]}` em ordem de importância.
    - O código ignora índices fora do intervalo ou repetidos e Tópicos sem índice válido.
    - Itens não referenciados vão para `fora_do_audio`.
    - Se a soma de `palavras_alvo` passar de `palavras_max * 0.85` (sobra para abertura e fechamento), os Tópicos do fim saem e seus Itens vão para `fora_do_audio`.
  - `escrever_abertura(llm, pauta: Pauta, data: date) -> tuple[Fala, ...]`, `escrever_bloco(llm, topico: Topico) -> tuple[Fala, ...]` e `escrever_fechamento(llm, pauta: Pauta) -> tuple[Fala, ...]`: o schema é `{"falas": [{"apresentador": "dora"|"alex", "texto"}]}`; Falas com apresentador desconhecido ou texto vazio são descartadas.
  - `aplicar_teto(roteiro: Roteiro, pauta: Pauta, palavras_max: int) -> tuple[Roteiro, Pauta]`: enquanto `roteiro.palavras() > palavras_max` e houver blocos, remove o último bloco e move os Itens do Tópico correspondente para `fora_do_audio`.
  - `prompts.py` guarda as instruções em pt-BR: as personas (Dora conduz a pauta, Alex comenta e contextualiza, tom descontraído e informativo), falar como podcast (sem markdown, sem ler URLs, números por extenso quando curtos) e respeitar `palavras_alvo`.
